# BOSS 消息助手

这是一个 Chrome 扩展，目标页面仅为：

`https://www.zhipin.com/web/geek/chat?ka=header-message`

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹：`boss-chat-assistant`。
5. 将“BOSS 消息助手”固定到 Chrome 工具栏。

首次刷新后的权限提示中，扩展会请求 Chrome 的“调试”权限。该权限只会在你点击发送任务时附加到当前 BOSS 消息标签页，用于输入文本并按下 Enter；任务结束后立即断开。

## 使用

1. 登录 BOSS 直聘并打开消息页。
2. 点击浏览器工具栏中的扩展图标。
3. 填写“唤醒消息模板”和／或“已读未回模板”；内容会保存于当前 Chrome 浏览器。
4. 如需跳过某位面试官，先在消息列表中打开其会话，再点击“排除当前面试官”。此名单长期保存，两个任务都会跳过其中成员。
5. 点击“一键唤醒全部面试官”或“跟进已读未回面试官”。任务只有在你点击时才会开始。
6. 需要停止时，打开扩展弹窗并点击“停止当前任务”。

“已读未回”的规则是：最后一条消息是你发出的、页面显示“已读”、且没有后续对方消息。运行结果会显示已发送、跳过和失败数量。

## 页面适配说明

网站更新可能会改变网页元素名称。所有页面元素定位规则集中于 [selectors.js](selectors.js)：

- `conversationContainer`：会话列表容器
- `conversationItem`：单个会话项
- `messageContainer` 和 `messageItem`：消息区域与消息项
- `input` 和 `sendButton`：消息输入和发送控件

如果弹窗提示“未找到消息会话列表”或“未找到消息输入框”，先在已登录的目标页面按 F12 查看实际元素，再仅修改上述数组中的 CSS 选择器，然后回到 `chrome://extensions/` 点击本扩展的刷新按钮。

## 边界

- 扩展不会定时运行或自行发送消息。
- 每次发送时临时使用 Chrome 调试协议向当前 BOSS 页面输入文本并按 Enter，结束后立即断开；不在其他网站操作。
- 不尝试绕过验证码、发送限制或风控提示；出现网站提示时请停止任务并按页面要求处理。
- 请自行确认消息内容准确，并遵守 BOSS 直聘的规则。
